# GTA 6 Brasil: tá pronto?

Página única, informal e em pt-BR, com horário, preço, plataformas e calculadora de espaço para o lançamento de Grand Theft Auto VI no Brasil (0h de 19/11/2026, horário de Brasília).

Site ao vivo: https://nexorabrai-debug.github.io/gta6brasil/

Não é afiliado à Rockstar Games, Take-Two, Sony ou Microsoft.

## Arquivos

- `index.html` — conteúdo
- `styles.css` e `app.js` — visual, contagem, calculadora e Pix
- `robots.txt` e `sitemap.xml` — SEO
- `og.png` — imagem de compartilhamento (só tipografia, sem arte oficial)
- `posts.md` — rascunhos de divulgação, não publicados

## Publicação

GitHub Pages a partir da branch `main`, na raiz do repositório.
